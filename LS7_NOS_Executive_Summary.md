## 6. The Two Core Experiments

### Experiment A — NLPI NOS Replication (LLM, Runnable Now)
**File:** [`Experiments/NLPI_NOS_Replication_Guide.md`](https://github.com/tchilzer2/ls7-nos-1-7-framework/blob/main/Experiments/NLPI_NOS_Replication_Guide.md)

**What it tests:** Whether NOS conditioning reduces semantic drift in a language model's long-horizon outputs.

**High-level protocol:**
1. Clone repo and install dependencies per README
2. Load the provided evaluation dataset (or equivalent long-horizon reasoning corpus)
3. Run baseline trials — standard model configuration, record metrics
4. Apply NOS conditioning: 13-window pacing, activator injection at STOP cadence, septenary token grouping
5. Run NOS-conditioned trials — identical seeds and compute resources
6. Collect metrics: semantic entropy, coherence score, error rate, drift slope over tokens
7. Run CAMI analysis pipeline for STOR proxies, cadence histograms, significance tests

**Success criterion:** p < 0.05 reduction in semantic entropy after multiple-testing correction.
